Файл сформирован `bench/analysis/analyze.py` из сырых CSV; числа не правились вручную. speedup = total(CPU) / total(кандидат) по медианам; total GPU включает аллокации, передачу данных и синхронизацию (§45, §48).

Входные файлы (1): `results_gpu_mldsa_empty_ctx.csv`

## Точки пересечения (speedup = 1)

Интерполяция линейная по log(speedup) от log(x) между соседними точками сетки. «Кандидат» — GPU-backend (kind = gpu) либо `cpu-mt` (kind = threads, против `cpu`).

### GPU против CPU

| операция | ось | фиксировано | кандидат | baseline | результат |
|---|---|---|---|---|---|
| mldsa_sign | по числу (batch) | размер 168 B | gpu | cpu | быстрее начиная с ≈ 15 (число объектов/листьев/batch) |
| mldsa_sign | по числу (batch) | размер 168 B | gpu | cpu-mt | быстрее начиная с ≈ 283 (число объектов/листьев/batch) |
| mldsa_verify | по числу (batch) | размер 168 B | gpu | cpu | быстрее начиная с ≈ 24 (число объектов/листьев/batch) |
| mldsa_verify | по числу (batch) | размер 168 B | gpu | cpu-mt | быстрее начиная с ≈ 258 (число объектов/листьев/batch) |

### cpu-mt против cpu

| операция | ось | фиксировано | кандидат | baseline | результат |
|---|---|---|---|---|---|
| mldsa_sign | по числу (batch) | размер 168 B | cpu-mt | cpu | кандидат быстрее на всём диапазоне (1…10 000) |
| mldsa_verify | по числу (batch) | размер 168 B | cpu-mt | cpu | кандидат быстрее на всём диапазоне (1…10 000) |
